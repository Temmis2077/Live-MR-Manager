OBS 오버레이
OBS 브라우저 소스 설정 가이드
• 곡 정보: 640 × 200 권장 (비율 16:5)
• 가사: 640 × 220 권장 (비율 32:11)
• 오버레이는 소스 크기에 맞춰 자동으로 조절됩니다 — 위 크기는 참고값일 뿐, 비율만 비슷하게 자유롭게 늘리거나 줄여도 자연스럽게 맞춰집니다.
• OBS에서 너비만 입력하고 높이는 자동 계산되게 하려면, 브라우저 소스 속성에서 원하는 너비만 입력 후 높이를 0으로 두면 비율에 맞게 자동 조절됩니다.
• 다른 PC에서 접속이 안 되면 Windows 방화벽에서 14201, 14202 포트(TCP) 인바운드를 허용해주세요.

인트로 자동 건너뛰기

유튜브 영상 앞에 뮤비 형식 인트로 등 노래와 무관한 구간이 있는 곡은, 가사 싱크 탭에서 "보컬 시작 지점"을 지정해두면 재생 시 그 지점으로 자동으로 건너뜁니다. 지점을 지정하지 않은 곡은 평소처럼 처음부터 재생됩니다.

우클릭 메뉴에 「재생」 표시

곡 우클릭 메뉴에 재생/일시정지 항목을 표시합니다. 기본은 숨김 — 곡 카드를 클릭해도 재생됩니다.

우클릭 메뉴에 「가사 보기」 표시

곡 우클릭 메뉴에 가사 보기 항목을 표시합니다. 기본은 숨김 — 화면 오른쪽 가사 드로어 버튼으로도 열 수 있습니다.

가져오기 · 백업

곡 정보 일괄 편집은 라이브러리 상단 곡 관리 버튼으로 옮겼습니다 (카테고리·장르·가사상태별 확인 + 표 편집).

엑셀(CSV) 가져오기 / 보내기

곡 목록을 CSV·엑셀로 내보내거나 가져옵니다. 양식 받기로 형식을 확인하세요. 같은 곡은 갱신되고 새 곡은 추가됩니다.

데이터 백업 및 복원 (JSON)

곡 목록을 파일로 백업·복원합니다. 복원 시 기존 곡은 유지됩니다.

MR 캐시 저장 위치

AI 분리 결과(보컬/MR)가 저장되는 폴더입니다. 네트워크 공유 폴더로 지정하면 여러 PC가 같은 분리 결과를 공유할 수 있습니다 (예: 고성능 PC에서 분리하고 다른 PC에서 재생). 변경은 앱 재시작 후 적용되며, 기존 분리 결과는 자동으로 이동되지 않으니 필요하면 기존 폴더 내용을 새 위치로 복사하세요.

GPU 가속 팩 (선택)

NVIDIA GPU에서 MR 분리 속도를 곡당 20~30분 → 약 30초로 줄입니다 (RTX 2070 실측). 용량이 약 4GB라 설치본에 넣지 않고, 아래 다운로드 버튼으로 원하는 분만 받는 구조입니다. 없어도 앱은 기존대로 동작합니다.
NVIDIA GPU 전용이며, 처음 분리할 때 GPU에 맞춰 엔진을 빌드하느라 2~3분 걸립니다(이후 캐시되어 바로 시작).
