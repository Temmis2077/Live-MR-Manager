# `v0.6.0-beta.*` Legacy 릴리스 기록

`v0.6.0-beta.1~6`은 OSW 독립 제품 전환 이전에 **Live MR Manager Mod** 이름으로
배포했던 설치본입니다. 2026-08-14에 현재 개발 상태와 크게 달라진 공개 설치본의 혼동을
막기 위해 GitHub Release 항목과 첨부 자산을 제거했습니다.

소스 이력 복구를 위해 Git 태그는 유지합니다. 이 설치본들은 지원 대상이 아니며 새 설치를
권장하지 않습니다.

| 태그 | 당시 공개 제목 | 핵심 변경 |
| --- | --- | --- |
| `v0.6.0-beta.1` | 모드 첫 베타 (AI 가사 정렬) | 한국어·영어·혼합 CTC 정렬, 정렬 대기열, 3줄 가사 편집, OBS 가사 뷰 |
| `v0.6.0-beta.2` | 통합 검색 · 가사 호버창 | 유튜브·가사 통합 검색, 인앱 가사 창, 키/BPM 자동 분석 |
| `v0.6.0-beta.3` | 장르/카테고리 정리 · 대기열 저장 · 자체 업데이트 | 분류 기준 통일, 대기열 복원, 다운로드 재시도, 자체 업데이트 경로 |
| `v0.6.0-beta.4` | MR 분리 GPU 가속 · 커스텀 모델 카탈로그 | CPU 최적화, TensorRT 실험, 커스텀 분리 모델 등록 |
| `v0.6.0-beta.5` | 가사 정렬 밀림 수정 · 정렬 디리버브 | 괄호 코러스, 혼합곡 병합, 앵커 재정렬, 정렬 전용 디리버브 |
| `v0.6.0-beta.6` | 멜로밍 UI 일시 비활성화 | 인증 키가 없는 멜로밍 UI 숨김과 beta.5 후속 패치 |

## 현재 버전과 다른 점

이후 개발 스냅샷에는 OSW 독립 식별자·데이터 경로를 비롯해 LRCLIB, 정렬 메타데이터,
보컬 활동 구간, 가사 진행도, 라이브 화면, 확장된 오버레이 편집, 백업·온보딩·단축키,
MR 캐시와 모델 경로 정리가 추가됐습니다. 따라서 `0.6` 설치본의 화면과 데이터 동작을
현재 README의 기능 설명으로 해석하면 안 됩니다.

현재 공개 상태와 다음 변경 묶음은 [README](../README.md)와
[Unreleased 변경 기록](../RELEASE_NOTES.md)을 참고하세요.
