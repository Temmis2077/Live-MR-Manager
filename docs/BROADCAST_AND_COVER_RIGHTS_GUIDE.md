# 방송·커버에 OSW를 사용할 때 확인할 것

> 조사 기준일 2026-08-14. 이 문서는 이해를 돕는 일반 안내이며 법률 자문이 아닙니다.

## 먼저 세 가지를 따로 보세요

1. **OSW 프로그램**은 MIT 라이선스입니다.
2. **AI 분리 모델**은 모델마다 조건이 다릅니다. MIT 모델을 골라도 노래 권리까지
   해결되는 것은 아닙니다.
3. **노래와 음원**에는 작사·작곡·가사 권리와 원본 녹음의 음반제작자·실연자 권리가
   따로 있을 수 있습니다.

즉, 상업 이용 가능한 모델로 원곡을 분리했더라도 원곡 음원을 방송·배포할 권리가
자동으로 생기지는 않습니다.

## 상황별 빠른 판단

| 하려는 일 | 안내 | 먼저 확인할 것 |
| --- | --- | --- |
| 내 PC에서 개인 연습 | 대체로 가능 | 모델의 개인 이용 조건, 합법적으로 보유한 음원인지 |
| 직접 연주한 반주로 비수익 방송 | 추가 확인 필요 | 곡의 공연·공중송신 조건과 플랫폼 정책 |
| 수익 방송 | 추가 확인 필요 | 모델 상업 이용, 곡 권리, 후원·광고를 포함한 플랫폼 조건 |
| 방송 다시보기·클립 유지 | 추가 확인 필요 | 라이브와 별도로 복제·전송되는 녹화물 정책 |
| 직접 만든 반주로 커버 영상 제작 | 추가 확인 필요 | 작사·작곡 권리와 편곡 여부, 플랫폼의 커버 처리 |
| 원곡을 분리한 MR로 방송·커버 | 피하는 것이 안전 | 원본 마스터와 실연자 권리까지 허가됐는지 |
| 분리한 MR·stem을 공유·판매 | 피하는 것이 안전 | 원본 음원 복제·배포 허가와 모델 재배포 조건 |
| 전체 가사를 화면에 표시 | 추가 확인 필요 | 가사 이용 및 공중송신 허가가 포함되는지 |
| 번역·개사·큰 편곡 | 추가 확인 필요 | 원저작물의 2차적저작물 작성 허가 |
| 커버 음원·영상을 유료 배포 | 추가 확인 필요 | 곡, 가사, 편곡, 녹음, 유통 플랫폼별 허가 |

“추가 확인 필요”는 곧 금지라는 뜻이 아니다. 곡과 플랫폼의 계약 범위가 서로 달라
OSW가 일괄적으로 허용을 보장할 수 없다는 뜻이다.

## 자주 생기는 오해

- **수익이 없으면 괜찮다?** 비수익이라는 사실만으로 저작권 이용 허락이 생기지는 않는다.
- **Content ID가 영상을 그대로 두면 허가된 것이다?** Content ID는 권리자가 차단·추적·
  수익화를 선택하는 플랫폼 관리 절차다. 모든 권리의 개별 허락 증명과 같지 않다.
- **AI 모델이 MIT면 결과도 마음대로 쓸 수 있다?** MIT는 모델 이용 조건이다. 입력한
  원곡과 가사, 원본 녹음의 권리는 별도로 남는다.
- **원곡에서 목소리만 지우면 내가 만든 MR이다?** 원본 녹음의 상당 부분이 남아 있으므로
  직접 연주·녹음한 반주와 같은 것으로 보지 않는 편이 안전하다.
- **방송이 가능하면 다시보기도 가능하다?** 라이브와 저장된 VOD·클립의 처리가 다를 수 있다.

## 플랫폼별 확인 경로

- YouTube는 라이브도 제3자 콘텐츠를 탐지하며, 라이선스를 보유해도 Content ID
  허용 목록 처리가 없으면 중단될 수 있다고 안내한다.
- YouTube는 일부 직접 녹음한 커버만 권리자의 Content ID 수익화 선택에 따라 수익화될
  수 있고, 상업 음원·기성 반주 녹음 사용에는 별도 권리가 필요하다고 안내한다.
- CHZZK, SOOP, Twitch는 방송을 시작하기 전 각 서비스의 최신 운영정책·저작권·음악
  지침을 직접 확인한다. 플랫폼 정책은 계정·국가·계약과 개정 시점에 따라 달라진다.

## 안전하게 준비하는 순서

1. 모델 카탈로그에서 `상업 이용 허용`과 출처를 확인한다.
2. 가능하면 원곡 분리 MR 대신 직접 연주·녹음했거나 이용 허락을 받은 반주를 쓴다.
3. 방송뿐 아니라 다시보기, 클립, 다운로드, 가사 표시까지 사용할 범위를 적는다.
4. 플랫폼 안내와 권리자의 허락 범위가 일치하는지 확인하고 기록을 보관한다.
5. 판단이 애매하면 권리자, 한국음악저작권협회 또는 저작권 전문가에게 확인한다.
